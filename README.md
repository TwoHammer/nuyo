Project Momo —— 双人互动电子宠物

一个可以随身携带、可以陪伴在身边，也可以连接两个人情感的智能电子宠物。

1. 项目简介

1.1 项目灵感

项目灵感来源于微雪电子（Waveshare）的 ESP32 圆形屏幕开发板。

以圆形显示屏为核心，设计一款兼具便携性、趣味性和情感交互属性的电子宠物设备。

它既可以作为日常随身携带的钥匙扣或背包挂件，也可以通过磁吸充电底座变成桌面电子宠物。

设备不仅拥有独立的宠物养成系统，还能够通过手机 App 和云端服务与另一台设备建立联系，让两个人通过电子宠物进行日常互动。

1.2 核心设计理念

* 陪伴： 让电子宠物成为日常生活中的陪伴者。
* 互动： 通过触摸、晃动、震动、声音和小游戏增加趣味性。
* 情感连接： 让两个人能够通过设备进行轻量化的情感交流。
* 便携： 室外可以随身携带，不给用户造成明显负担。
* 个性化： 宠物拥有自己的状态、性格、成长和表现形式。

1.3 产品定位

一款面向情侣及年轻用户的便携式智能电子宠物。

它融合了：

* 电子宠物养成
* 智能硬件
* 蓝牙通信
* 手机 App
* 云端数据同步
* 双人情感互动
* 轻量级游戏

2. 产品形态与使用场景

2.1 设备外观

* 圆形设计，以圆形显示屏作为主要交互界面。
* 小巧轻便，方便日常携带。
* 具备挂绳孔或钥匙扣结构。
* 具有磁吸充电接口或磁吸充电底座。
* 尽可能采用简洁、可爱、有辨识度的外观设计。

2.2 双模式设计

模式 A：室外便携模式

使用场景：

* 挂在钥匙上。
* 挂在背包上。
* 随身携带。

设计目标：

* 低功耗运行。
* 尽可能延长电池续航。
* 减少屏幕刷新和不必要的动画。
* 保留宠物核心状态显示。
* 支持必要的互动提醒。
* 支持蓝牙通信。

模式 B：室内桌面模式

使用场景：

* 放置在书桌上。
* 放置在床头柜上。
* 作为桌面装饰摆件。

设计目标：

* 通过磁吸底座进行充电。
* 支持长时间运行。
* 展示更加丰富的宠物动画。
* 支持更多交互效果。
* 可以作为桌面时钟或信息显示终端。
* 增加宠物与用户之间的互动频率。

2.3 两种模式的切换

初步考虑通过以下方式实现：

* 检测充电状态。
* 检测磁吸底座连接状态。
* 根据供电状态自动切换运行策略。

3. 核心功能需求

3.1 电子宠物系统

这是整个项目最核心的功能。

宠物需要拥有自己的状态和行为逻辑。

初步设计：

功能	描述
宠物展示	显示宠物形象和基础动画
心情系统	开心、难过、困倦、兴奋等
饥饿系统	根据时间变化产生饥饿状态
精力系统	宠物具有精力值，会休息和活动
亲密度系统	根据用户互动积累亲密度
成长系统	根据陪伴时间和互动逐步成长
行为系统	根据不同状态触发不同动作
反馈系统	通过动画、声音、震动反馈用户操作

后续可以考虑加入：

* 宠物性格。
* 宠物等级。
* 宠物装扮。
* 宠物生日。
* 特殊节日和纪念日。
* 随机事件。

3.2 设备交互系统

利用设备自身的硬件实现丰富的互动。

陀螺仪 / 姿态传感器

* 摇晃设备。
* 翻转设备。
* 检测设备姿态。
* 触发宠物不同的动作。
* 根据运动状态触发小游戏。

震动马达

* 消息提醒。
* 宠物互动反馈。
* 特殊事件提醒。
* 双人互动时的触觉反馈。

扬声器

* 宠物叫声。
* 操作音效。
* 游戏音效。
* 特殊事件提示音。

显示屏

* 宠物动画。
* 状态展示。
* 游戏界面。
* 通知提醒。
* 时间和日期。

3.3 小游戏系统

设备本身支持简单的小游戏，增强可玩性。

初步考虑：

* 猜数字。
* 反应力测试。
* 摇晃挑战。
* 简单的躲避游戏。
* 宠物互动小游戏。

后续可以考虑双人游戏，让两台设备通过 App 或云端配合完成挑战。

4. 双人情感互动系统

这是 Project Momo 区别于普通电子宠物的核心特色。

设备不仅是一个独立的宠物，也可以成为两个人之间的情感媒介。

4.1 双人绑定

* 两台设备可以进行配对。
* 两个用户通过手机 App 建立关系。
* 每台设备对应一个用户。
* 两台设备共享部分互动数据。
* 支持解除绑定和重新绑定。

4.2 情感互动

初步设想：

功能	交互方式
想念对方	发送一个特殊的宠物动作或提醒
远程摸摸	一方在 App 操作，另一方设备产生反馈
发送心情	发送表情或心情状态
发送爱心	设备播放爱心动画并震动
日常问候	发送早安、晚安等互动
远程陪伴	两只宠物进行特殊联动
亲密度	通过双人互动积累专属亲密度

4.3 专属互动玩法

可以考虑设计一些具有情侣专属属性的玩法：

* 两只宠物能够在屏幕上进行互动。
* 一方触发动作，另一方的宠物能够作出回应。
* 双方每天完成指定互动任务。
* 记录两个人的共同陪伴天数。
* 纪念日自动触发特殊动画。
* 通过两台设备完成双人小游戏。
* 设计只有双方共同参与才能解锁的宠物装扮或动作。

4.4 情感表达

希望设备能够让用户不需要打开手机，也能感受到对方的存在。

例如：

* 对方发送消息时，设备轻轻震动。
* 对方想念自己时，宠物出现特殊表情。
* 双方同时互动时，宠物产生特殊动画。
* 特殊日期到来时，宠物主动送上祝福。

6.4 消息服务

* 双人互动消息转发。

* 离线消息保存。
* 消息送达状态。
* 特殊事件推送。

6.5 设备通信架构

初步考虑：

设备 → 蓝牙 BLE → 手机 App → 网络 → 云端服务器

另一台设备通过其手机 App 接收数据，再通过 BLE 将互动指令发送给设备。

这样可以避免设备必须始终连接 Wi-Fi，降低室外使用时的功耗。

如果后续硬件具备 Wi-Fi，也可以考虑让设备在室内直接连接云端。

11. 项目核心原则

1. 电子宠物是核心，不能让设备变成单纯的消息通知器。
2. 室外便携和室内桌面是两种不同的使用体验。
3. 双人互动应该自然、轻量，不应该给用户造成额外负担。
4. 尽可能降低功耗，保证随身携带的实用性。
5. 设备在没有手机和网络的情况下，也应该能够独立运行。
6. 手机 App 和云端服务是增强体验的部分，不应该成为设备正常运行的必要条件。
7. 优先完成核心体验，再逐步增加复杂功能。
